## Notes
Open index.html file in web browser, it has been validated in chrome. For extra credit I added a color box next to the species name in table to assist visualization. Additionally for extra credit I created labels for the clicked data.


## Included files

* a06.js - A skeleton file was provided in the given repository to create two scatterplot visualizations. It has been modified to include a completed makeScatterplot() function and onBrush() function.
* d3.js - This file contains the D3 library included in given repository.
* index.html - An HTML file which displays the scatterplots and table, provided in the given repository.
* iris.js - This file contains the iris dataset, it was provided in the given resository.
* README.md - This file. It contains the assignment and author information.
* style.css - This file styles the color-box used in the HTML table.
