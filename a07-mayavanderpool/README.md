## Notes

Open index.html in any web browser. It has been validated in HTML. For extra credit I created a button that inverts the axes by switching the minimum and maximum. However, I was not able to get the brushed area to move as well so it covers the same points on the axes after inverting instead it remains in place. I also created a helper function to redraw the data moving the contents of onClick out of the function.

## Included files

* README.md - This file. Contains author and assignment information
* a07.js - This file contained a skeleton file in given repository for creating a parallel coordinate visualization. I modified it to draw data, axes, and implement brush and click interactions.
* d3.js - This file contains the d3 library it was provided in the given repository.
* index.html - This file was given in the provided repository. It contains links to the javascript files, dataset, and d3 library.
* penguins.js - This file was given in the provided repository. It contains penguin data.
* button.js - This is a file created for extra credit. It's purpose is to add a button to the index.html that allows users to invert the axes.
