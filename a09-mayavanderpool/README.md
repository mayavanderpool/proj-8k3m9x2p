## Notes
Open index.html in a web browser, it has been validated in chrome. For extra credit I added labels to the plots, and created a tooltip that calculated the average value of the cell being hovered over.


## Included files

* README.md - This file, skeleton provided in given repository. This file contains author and assignment information.
* index.html - Provided in given repository. Contains html elements to display plots, altered to be valid and for extra credit elements.
* a09.js - Provided in given repository. Modified to complete functions includesFilledContour, generateContourOutline, and generateFilledContour. Computes isocontour plots.
* d3.js - Provided in given repository, includes the d3 library.
* data.js - Provided in given repository, contains a slice of the Hurricane Isabel dataset. 
* style.css - Provides styling for extra credit elements.
