## Notes
Open index.html in a web browser, it has been validated in google chrome. For extra credit I created borders for the buttons that match their respective color scales when clicked. The purpose of this is to allow the user to remember which button they clicked. While working on this I fixed a console error about the VR not being initialized prior to updating.


## Included files

* README.md- This file, outline provided in given repository. Includes assignment and author information.
* index.html- Provided in given repository, includes template html. Modified to include two more buttons, and validate.
* a10.js- Provided in given repository with skeleton code. Implements transfer functions to be used in volume rendering.
* d3.js- Provided in given repository, contains the d3 library.
* volren.js- Provided in given repository, contains functions to create the vtk.js volume renderer canvas and update its transfer functions.
* vtk.js - Provided in given repository, contains the vtk.js library.
* datasets- Provided in given repository, contains four datasets to be rendered.
